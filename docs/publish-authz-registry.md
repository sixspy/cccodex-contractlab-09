# 发布鉴权册（契约发布授权登记）

- 登记日期：2026-11-18
- 选定壬列：**乙路径**（申请 → 审批 → 服务端切指针）
- 鉴权落点：**服务端唯一一径**（FastAPI 后端）。前端隐藏按钮不构成鉴权；前后端不得混用鉴权支。
- 本册选定当日不得改口；任何偏离本册的请求一律拦下并记审计「鉴权偏离」。

## 口径

1. **发布写入口仅一径**：`POST /api/publish-requests`（提交申请单）→ `POST /api/publish-requests/{id}/approve`（值班管理员审批）→ **服务端**原子切换正式指针。无第二路径。
2. **只读账号**：可登录、可提交申请单；不得直发启用、不得审批。只读令牌直发或审批 → `403`，**零写入**，记审计「鉴权偏离拦截」。
3. **直发入口关闭**：`POST /api/contracts/publish` 对任何角色一律 `403` 并记「鉴权偏离拦截」。正式启用仅审批办结后由服务侧切指针。
4. **正式指针**（`track='正式'` 且 `status='启用'`）仅由服务端在审批办结后于同一事务内切换：新版本置「启用」，同主题旧正式版置「停用」。
5. **审批争用**：同一申请两名值班同时抢审批，以状态机原子认领排队（`UPDATE ... WHERE status='待审批'`），先到办结，后到 `409` 并记审计「审批争用」。
6. **鉴权页序**：登录态（401）→ 角色（403，记偏离）→ 资源存在（404）→ 状态机（409，记争用）。

## 可核页面

版本目录（契约版本）、申请列表（发布申请）、处置卡片（审批处置）、审计附页（审计日志）、策略说明（本册摘要）。
